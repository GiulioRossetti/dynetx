# v0.4.0 Diff Summary

This commit groups the usability and interoperability expansion for DyNetx into one changeset.

## Core Graph API

Files:
- `dynetx/classes/dyngraph.py`
- `dynetx/classes/dyndigraph.py`
- `dynetx/classes/function.py`

Changes:
- Added real edge and node removal methods for both graph types.
- Added edge-level mutation helpers: `add_edge`, `add_edges_from`, `edges_iter`, `edges`, and directed `in_edges` / `out_edges`.
- Added temporal helper APIs:
  - `temporal_degree()`
  - `avg_temporal_degree()`
  - `has_node_in_range()`
  - `has_interaction_in_range()`
  - `neighbors_in_range()`
  - `interactions_in_range()`
  - `window_slices()`
  - `to_networkx_graph()`
- Extended `time_slice()` to support `node_filter`, `edge_filter`, and `include_isolated`.
- Fixed edge attribute writes so metadata is preserved on temporal interactions.
- Fixed presence checks and conversion paths so overlapping intervals are handled safely.

## Temporal Analytics

Files:
- `dynetx/algorithms/temporal.py`
- `dynetx/algorithms/__init__.py`
- `dynetx/test/test_algorithms.py`

Changes:
- Added temporal centrality helpers:
  - `temporal_degree_centrality()`
  - `temporal_earliest_arrival_closeness()`
  - `temporal_betweenness_centrality()`
- Added temporal structure helpers:
  - `temporal_clustering()`
  - `temporal_transitivity()`
  - `temporal_connected_components()`
  - `path_support()`
- Exported the new algorithms from the package namespace.
- Added tests for the new temporal metrics and path summaries.

## Interoperability and I/O

Files:

- Kept the edgelist parser/writer compatible with the new interval semantics.
- Added tests for JSON, GraphML, and tabular round-trips.
